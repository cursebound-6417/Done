# HIGH SCHOOL — THE GAME

Fresh rebuild. Includes all 20 original questions, rooms for up to 100 players, QR joining, host controls, live answer status, and WebSocket realtime updates.

## Run
npm install
npm start

For 24/7 use, deploy this Node.js app on an always-on service. The application itself does not intentionally shut down rooms; hosting uptime depends on the provider.
